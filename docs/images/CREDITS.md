# Demo image credits

Original: [Forest walk 05.jpg](https://commons.wikimedia.org/wiki/File:Forest_walk_05.jpg), photographed by **Jojovavasasa**, 5 July 2026. Published by the photographer under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

`demo-before.jpg` is an oriented, resized JPEG copy. `demo-after.jpg` is that copy processed by Style Studio. `editor.png` is a real capture of the application with this example loaded. The demonstration shows **desktop colour processing**, not RAW decoding, a camera-written Picture Style, or a photograph shot with the exported style. The source camera is a PowerShot SX730 HS, not a claim of USB installation compatibility with that model.

Example generator settings: temperature +28, red gamma +10, blue gamma -12, toe +25, shoulder +18, colour density +18 and saturation -15. All other generator settings are neutral.
